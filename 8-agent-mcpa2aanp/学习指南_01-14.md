### ⚠️ 本章最大的运行坑：`python` 子进程 PATH

本章几乎所有脚本都会用 `"python"` 字符串 **spawn 子进程**（MCP stdio 服务器、`MCPClient(["python", "xxx.py"])`）。
子进程继承的是 **PATH 里的 python**，不是你现在跑脚本的解释器！裸跑时 PATH 里是 Hermes 的 3.11 venv（无 fastmcp），子进程起不来、报错极具误导性。

**正确姿势（跑任何脚本前先执行）：**

```bash
cd <项目根>/8-agent-mcpa2aanp
export PATH="<项目根>/.venv/Scripts:$PATH"
python 01_TestConnect.py
```

验证：`which python` 应指向 `.venv/Scripts/python`。npx 需要 Node（本机 v22.22.2 已有）。

## 五、已知坑清单（实测踩过的，排错时先查这里）

1. **PATH 里的 python ≠ venv python**：忘 `export PATH` 时子进程报的是 fastmcp 缺失之类的"下游症状"，父进程只看到"连接超时/断开"。见第二节。
2. **a2a-sdk 必须钉 0.3.x**：1.1.2 会让 `A2A_AVAILABLE=False`，07/08 只会打印"请安装 a2a-sdk"（明明装了）。同 qdrant-client 1.16 坑，症状都是"装了但探测说没装"。
3. **protobuf 版本回钉**：a2a-sdk 拉 7.x 会砸第 4 章 autogen-core；`pip install "protobuf~=5.29.3"` 后 `import autogen_core` 恢复。
4. **fastmcp 启动横幅很长**：每个 FastMCP 子进程都打一个大 ASCII banner + "3.0 coming" + "4.0.4 available"，别误以为出错；`pip install --upgrade fastmcp` **不要**做（extras 锁 <3.0.0）。
5. **A2A 脚本端口互斥**：09 系用 5000–5002，10_WithAgent/CustomerService 用 6000/6001，10_Negotiation 用 7000/7001。脚本里全是 `daemon=True` 线程 + `while True`，**上一个没 Ctrl+C 干净退出，下一个就 BindError**；Windows 下用 `netstat -ano | findstr :5000` 找 PID 处理。
6. **`timeout 60 python xx.py | grep` 看不到输出**：stdout 重定向进管道有缓冲，脚本被 timeout 杀死时缓冲区丢了。看输出用 `-u` 参数或直接前台跑。
7. **SimpleAgent 的工具调用是提示词协议**（`[TOOL_CALL:...]`），对模型格式遵循度敏感：M3 的 `<think>` 块经常破坏格式（05 里它干脆不调工具直接口算 579；14 demo 里 TOOL_CALL 不闭合）。第 7 章同款问题，非本章 bug。
8. `09_A2A_Network.py` 的 writer 技能用 `eval()` 解析上游传来的字符串 dict——教学简化，别学进生产代码。
9. **03/06 的 GitHub token**：申请 [fine-grained PAT](https://github.com/settings/tokens)（Public repos 只读即可），填进 `.env` 的 `GITHUB_PERSONAL_ACCESS_TOKEN=`。注意 server-github 这个 npm 包走的是旧 env 名 `GITHUB_PERSONAL_ACCESS_TOKEN`，MCPTool 会把当前进程环境变量传给子进程，所以 `.env` 配好后 load_dotenv 的脚本里才能用。
10. 本目录**数据不落盘**：ANP 注册、A2A 服务都是进程内存态，跑完即消失，反复跑无副作用（与第 6/7 章"跨轮次累积"相反，可以放心随便跑）。
11. **（2026-09-20 已修复）PyCharm 里跑 02/03/04/05/06 报 `FileNotFoundError: [WinError 2] 系统找不到指定的文件`**：
    根因不是 Python 的 PATH，而是**子进程要 spawn 的 `npx` 找不到**——本机 `D:\Program Files\nodejs` 是残缺安装（只有 node.exe v23，npm/npx 被删掉了）。
    已用 npmmirror 官方 zip（node v22.20.0，npm 10.9.3）把 `npm/npx/corepack` shim 与 `node_modules/npm` 补回原目录，**未动现有 node.exe 和已装全局包**（@fission-ai、@openai），无需重启电脑。
    命令行跑（Git Bash）时先 `export PATH="<项目根>/.venv/Scripts:$PATH"` 即可；**PyCharm 里跑则注意**：运行配置的工作目录（Working directory）要设成 `8-agent-mcpa2aanp`，
    否则脚本里的 `MCPClient([..., "."])` 允许目录和 `read_file("my_README.md")` 相对路径都会指到项目根而报错。
