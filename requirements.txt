# ============================================================================
# hello-agent-learn 全工作区统一依赖清单（第 1–6 章）
#
# 适用环境：Python 3.12（必须是 3.12+，见下方说明）
# 安装（在项目根目录执行）：
#   .venv/Scripts/python.exe -m pip install -r requirements.txt
#
# 【为什么必须 Python 3.12】
#   numpy==2.5.3 要求 >=3.12，pandas==3.0.5 / scikit-learn==1.9.1 要求 >=3.11。
#   原先根目录的 Python 3.10 环境装不上这三个包（实测 pip 直接报
#   "Could not find a version that satisfies the requirement scikit-learn==1.9.1"）。
#
# 说明：本清单只列【直接依赖】并锁定精确版本，传递依赖交由 pip 解析。
#       若需要完全一致的传递依赖快照，执行：
#   .venv/Scripts/python.exe -m pip freeze > requirements.lock.txt
#
# 注意：第 4 章的四个对比框架演示（AgentScope / AutoGen / CAMEL / LangGraph）
#       依赖另见 requirements-frameworks.txt，本文件不含。

# 1. 框架本体（第 5、6 章需要）
# ---------------------------------------------------------------------------
# PyPI 上 hello-agents 最新已是 1.0.0，API 与本书示例不兼容，必须锁 0.2.9。
# 从 0.1.1 升到 0.2.9 不会破坏第 5 章代码——实测 ToolRegistry / HelloAgentsLLM /
# SimpleAgent / ReActAgent / ReflectionAgent / PlanAndSolveAgent / Config / Message /
# CalculatorTool / Planner / Executor 在 0.2.9 下全部存在（0.2.9 是 0.1.1 的超集）。
#
# 为什么不带 [all] / [memory,rag] extras：
#   - [all] 会展开出 rl 组（trl/bitsandbytes/wandb/tensorboard 等，约 1-2 GB，
#     是第 11 章 RL 训练才用的），其中 torch>=2.0.0 无 CPU 标记会覆盖 CPU 版 torch，
#     evaluation 组的 gradio<5.0.0 还会把 gradio 降级到 4.x —— 千万别装；
#   - 本清单下方已显式列出所需的全部依赖且版本更精确，extras 完全不需要。
