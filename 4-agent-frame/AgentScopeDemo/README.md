# AgentScope 三国狼人杀

> 基于 [Hello-Agents](https://hello-agents.datawhale.cc/) 第六章「框架开发实践」—— AgentScope 框架部分的学习实践。

## 项目简介

本项目使用阿里巴巴 [AgentScope](https://github.com/modelscope/agentscope) 框架（v1.0.2），构建了一个由 6 个 AI 智能体参与的**三国主题狼人杀游戏**。

程序启动后，6 位三国角色（刘备、关羽、曹操等）被随机分配身份，按照 **夜晚行动 → 白天讨论 → 投票淘汰** 的经典狼人杀流程进行博弈，直到某一阵营达成胜利条件。

## 游戏规则

### 阵营与身份

| 阵营 | 身份 | 人数 | 技能 |
|---|---|---|---|
| **狼人阵营** | 狼人 | 2 | 夜晚协商击杀一名玩家 |
| **好人阵营** | 预言家 | 1 | 每晚查验一名玩家身份 |
| **好人阵营** | 女巫 | 1 | 拥有解药和毒药各一瓶 |
| **好人阵营** | 村民 | 2 | 无特殊技能，依靠推理投票 |

### 三国角色

9 位三国名将随机分配 6 位上场，每位角色有独特的性格特征影响其发言风格：

| 角色 | 性格特点 |
|---|---|
| 刘备 | 仁德宽厚，说话温和有礼 |
| 关羽 | 忠义刚烈，言辞直接 |
| 张飞 | 性格豪爽，容易冲动 |
| 诸葛亮 | 智慧超群，分析透彻 |
| 赵云 | 忠勇双全，话语简洁有力 |
| 曹操 | 雄才大略，话语犀利 |
| 司马懿 | 深谋远虑，城府极深 |
| 周瑜 | 才华横溢，分析精准 |
| 孙权 | 年轻有为，话语果决 |

### 胜利条件

- **好人阵营**：消灭所有狼人
- **狼人阵营**狼人数量 ≥ 好人数量

## 核心概念

- **ReActAgent**：具备推理与行动能力的智能体，支持结构化输出和消息观察
- **MsgHub**：消息广播中心，实现多智能体之间的消息共享与自动广播
- **sequential_pipeline**：顺序执行管道，智能体按顺序依次发言
- **fanout_pipeline**：扇出执行管道，多个智能体并行处理同一消息（如投票）
- **OpenAIMultiAgentFormatter**：多智能体对话格式器，管理多轮对话上下文
- **Structured Output**：通过 Pydantic 模型约束智能体输出格式（投票、女巫行动、狼人击杀等）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> `requirements.txt` 中指定了 `agentscope==1.0.2`，该版本依赖 `mcp<2.0.0`。如遇导入错误，请确保 `mcp` 版本不超过 1.x。

### 2. 配置环境变量

复制 `.env_example` 为 `.env`，填入你的模型配置：

```bash
cp .env_example .env
```

`.env` 配置项说明：

| 配置项 | 说明 | 示例 |
|---|---|---|
| `LLM_MODEL_ID` | 模型名称 | `deepseek-v4-flash-0731` |
| `LLM_API_KEY` | API 密钥 | `sk-xxx` |
| `LLM_BASE_URL` | API 地址（兼容 OpenAI 格式） | `https://your-api.com/v1` |

> 支持任何兼容 OpenAI API 格式的服务，如 OpenAI、DeepSeek、阿里云百炼等。

### 3. 运行

```bash
python main_cn.py
```

## 游戏流程

每轮游戏按以下顺序执行：

```
夜晚阶段
  ├── 🐺 狼人讨论 → 投票选择击杀目标
  ├── 🔮 预言家查验 → 获取目标身份
  └── 🧙‍♀️ 女巫行动 → 决定是否使用解药/毒药
      ↓
  检查胜利条件
      ↓
白天阶段
  ├── ☀️ 全员讨论 → 依次发言
  ├── 🗳️ 全员投票 → 淘汰一名玩家
  └── 🏹 猎人技能 → 被投票出局时可带走一人
      ↓
  检查胜利条件 → 未结束则进入下一轮
```

## 注意事项

- 每轮游戏涉及 6 个智能体的多轮对话与多次 API 调用，运行时间取决于 API 响应速度
- 游戏最多进行 10 轮（`MAX_GAME_ROUND`），每轮白天讨论最多 3 轮（`MAX_DISCUSSION_ROUND`）
- 智能体的输出通过 Pydantic 结构化模型约束，但 LLM 仍可能返回异常结果，程序对此做了防御性处理
- 角色性格会影响智能体的发言风格，但不影响游戏机制逻辑
